# Bike Sales Dashboard (Excel)

## Project Overview

This project analyzes customer bike purchase behavior using Excel. The goal was to clean raw data, build Pivot Tables, and create an interactive dashboard to generate business insights.

## Dataset

* Bike Buyers Dataset
* Includes customer demographics, income, commute distance, age, and bike purchase status.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* IF Functions
* Data Cleaning

## Steps Performed

* Removed duplicate records
* Standardized categorical values
* Created age brackets using IF formulas
* Built Pivot Tables for analysis
* Designed an interactive dashboard with slicers

## Key Insights

* Customers with higher income purchased more bikes
* Middle-aged customers bought more bikes compared to younger customers
* Commute distance impacted purchase behavior
